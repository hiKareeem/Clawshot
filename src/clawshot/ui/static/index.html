Hookshot 2.0.12+

      

        Quit the game before changing mods. Put exactly one mod under a
        dedicated mods root:
      

      
mods / seed-name / seed-name / romfs / …

      

        Set HOS_MODS to the dedicated mods/seed-name folder. Clear
        HOS_FS_OVERLAY; never set it. Use real folders, not links. Button icons
        in seed text are the game's own.
      

      

        Back up your saves first. Manual mod loading uses the
        main save; a new game overwrites the playthrough. Prefer an isolated
        user folder. This UI does not start the game.
      

      
Emulator

      

        Install the generated folder as a RomFS / LayeredFS mod for this game's
        title in your emulator's mod directory. Enable it in Add-ons. Back up
        your saves before New Game.
      

      

        See docs/seed-pack.md for runtime-specific paths and
        seed-pack Play with isolated saves.
